# Partitura → MIDI (PWA)
1. Crie um repositório no GitHub e envie estes 5 arquivos na raiz.
2. Settings → Pages → Branch `main` / pasta `/ (root)` → Save.
3. Abra `https://SEU-USUARIO.github.io/NOME-DO-REPO/` no celular ou PC e use "Instalar app" / "Adicionar à tela inicial".
4. Abra uma vez com internet (as bibliotecas ficam em cache depois disso).
